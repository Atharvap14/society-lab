## Executable prospective probe

**Question:** When a correction becomes available after a relay's first scheduled decision, does an alternate information route rescue final accuracy?

Use the existing [relay environment](../swarm_lab/revision_relay_env.py) and [registered runner interface](../swarm_lab/revision_relay_experiments.py), without adding an artifact-readiness gate. Scripted source A generates independent revision-1/revision-2 residues modulo 97; C has an independent private residue. B and C are two subjects, each with two decisions. Abstract roles are synthetic; they do not map identified Village agents onto a verified chain. Requests contain only scoped delivered records and own history, excluding arm labels, seeds, oracle and future packets.

| Assigned factor | Levels |
|---|---|
| Correction availability to B | Early, before B's first decision; late, between B's two decisions |
| Direct route to C | Informative revision-2 packet; unrelated sham packet in the identical final slot |

The randomized unit is the **whole two-subject team**. Each seed block contains four fresh teams, one per cell, with cell order randomized within the block. Source records, C's private residue, target and fixed schedule are paired across cells; mutable state, memory and previous outputs are not shared. Blocks supply uncertainty units. Same world seed does not seed provider sampling.

Source boundaries are 0, 1, 4 and 6; subject decisions B2, C3, B5, C7. B receives the same final packet multiset under early/late ordering. B can forward a known canonical record or wait; C can draft and then explicitly revise, retain or wait. Invalid/empty actions consume opportunities. Both late/sham and the other cells remain legally solvable. Fixed contacts/sham formats do not make context order, informative exposure, direct-source authority, repetition or semantic salience identical.

**Primary outcome:** C's explicit final revision-2 answer equals the code oracle `(revision2 + C_private) mod 97`. A lucky correct guess scores; no attachment/receipt qualification applies. Missing/invalid final action scores zero; a draft carries forward only through valid explicit `retain`.

**Estimand:** block-average assigned-policy contrast

`D = (late_sham − early_sham) − (late_informative − early_informative)`.

A negative D is consistent with the predicted route rescue in this analogue. Report cell means and each block's D; do not condition on forwarding, receipt, draft error or canonical inventory. Null/reversed output weakens the specified prediction but does not establish equivalence. The current runner supplies **no interaction p-value**; its default interval is unavailable because independence/stability are not declared. Two blocks are an operational pilot, not a powered mechanism test. All-label permutations would test a global sharp null, not zero interaction with main effects.
