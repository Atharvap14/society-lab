# Independent build-completion audit

**Audit snapshot: 2026-10-04 02:50 UTC.** This is a read-only assessment of the original request, current code, immutable registry versions, saved execution evidence and runtime metadata. It does not promote a library record, run a model, register an experiment or certify later changes. The database was opened read-only; source review used code and bounded saved evidence, not a new full-corpus read.

**Decision:** a functioning, bounded research instrument exists, and the requested minimum of one real-data-to-research-to-wind-tunnel-to-evaluation-to-theory workflow has been demonstrated with live agents. Several original ambitions remain partially exercised. In particular, automatic routing from a newly discovered graph behavior through a suitable authored environment is incomplete; the saved live authoring attempts have not reached an approved executable world. Cheap model-based identification is operationally unavailable on this laptop/configuration. Historical communication exposure remains much less established than lexical graph structure. These are useful next implementation targets during the remaining build window. Neither exhausted requests nor additional successful tests alone would establish completion.

## Scope and evidence standard

The user asked for computational social science over agent societies: behavioral observability, graph-guided parallel discovery, a behavior/theory library, agentic causal experiment and environment design, private thought-like interventions, reusable harnesses with improved tools/prompts/skills, a fidelity/interaction framework, and a functioning end-to-end workflow. Attention allocation was explicitly dropped. The user also asked to avoid prematurely fixing the behavior ontology. NemoClaw, Codex and Claude Code were examples of usable harnesses, not three mandatory integrations. A universal browser simulator, arbitrary generated executable code, a positive scientific finding, training on Village, or proof of literature novelty was not an explicit completion condition.

The strongest evidence here is a pinned registry object plus independently checked actions/source/archive and deterministic analysis. A passing mock or scripted policy demonstrates a software contract, not LLM behavior. A model's cited interpretation is a hypothesis; membership of a citation in the evidence packet does not establish entailment. A registered synthetic experiment can identify a limited intervention package in its world without identifying what caused a historical Village episode.

Authoritative state at this snapshot is [BUILD_STATE.json](../BUILD_STATE.json), [pipeline.py](../swarm_lab/pipeline.py), the scientific modules linked below and read-only `.runtime/lab.sqlite3`. The loopback `/api/state` responded and reported 397 reserved/attempted calls, 394 completed calls, no active jobs and the configured research harnesses. UI availability does not independently test every screen. The existing report is a derived presentation, not a substitute for registry/source replay.

The compiler and registration bridge are functioning; the saved live agent-authored path has not passed the substantive review gate. Some blocked proposals predate the now-implemented resource factory, so their old missing-capability conclusions must not be generalized to the current catalog. A new exact review is needed, rather than silently overriding an old block.

**Historical communication exposure and outcome truth.** The graph instrument is sensitive to name eligibility: on a fixed five-node diagnostic universe, exact matching yields 62 pairs, explicit short-name expansion 143, Unicode shadow 81 and combined expansion 162. Incoming `o3` matches change from zero to 77 through the instrument, not a change in historical behavior. Selected-lead sensitivity retains the original windows/comparisons; one concentration contrast changes +.335 to -.114 under short-name expansion. Strict temporal paths preserve direction, timestamp ties and room scope, but name-reference chains are not receipt/use/influence paths.

The actual `source_link_audit-dcdbaca46070` v1 (`532924c84ea1142525dcee52d3437f6f5b9d2ce4850be117d4baadb2d02b9f44`) freshly reproduces 131 retained rows, 103 explicit relation attempts, three scoped matches, 93 unresolved parents and seven missing foreign keys across four partial scans. It is a retrospective known-prefix probe at other dates. It cannot corroborate the April graph candidates, imply corpus-wide absence, infer reads from missing chat, or certify tool success. Root's selected-window event-index work is in progress at this audit; it is not counted as completed evidence here.

**Cheap model measurement.** The pinned Laya attempt used revision `7b928d828b7b0e022f929d9bd2e44165aa270148`, a one-thread CPU worker and bounded startup. Available physical memory was about 0.41 GiB versus a 2.5 GiB gate, so the checkpoint was not loaded and no labels were produced. Jev had no authorized provider credential and made no request. The 16-example authored regex benchmark includes a quoted completion false positive and completion-report precision 0.5. It is useful diagnostic evidence, not representative precision on Village. Operational failures remain unknown rather than false observations.

**Novelty and general theory.** Agents can search local evidence and read bounded primary-source theory notes. There is no autonomous external literature novelty-verification tool, and no claim of novel-to-the-literature behavior is established. A useful library can retain novel-to-library candidates, negative results and theories awaiting replication. Generating a positive novel behavior cannot be guaranteed as a software completion condition. The correct remaining task is a functioning search/comparison contract with uncertainty, not forcing a novelty label.

## Highest-impact remaining functional work

1. **Add usable selected-window source/contact indexing with explicit coverage.** Connect actual message/session/provider coordinates and field-backed relations to the selected chronological windows, separately from lexical mentions. Expose what is and is not observed, retain unmatched parents and never convert absent exports into noncommunication. This directly improves discovery evidence and negative cases. The ongoing event-index implementation addresses this gap; a prefix smoke test at unrelated dates does not close it.
2. **Compose the agentic paths for non-artifact candidates.** Extend orchestration from discovery through capability requirements, exact blueprint, substantive review, compatible frozen registration, execution, evaluation and theory. Preserve an explicit stop/extension record when no environment fits. `Lab.workflow` currently chooses only `shared_artifact_coordination`; the newer authoring functions exist as separate actions. One successful saved authored-and-reviewed path would demonstrate the composition without requiring arbitrary generated code or a positive mechanism result.
3. **Make measurement usable and calibratable.** Keep regex as a named independent instrument; provide bounded human-readable adjudication/labels and realistic negative cases, then report precision/abstention with a declared sample. A usable Laya/Jev run requires appropriate hardware or provider credentials. Adapter fixtures cannot substitute for that deployment. Source qualifier, reported speech, model comparison and task-specific waiting need operational definitions before stronger behavior labels.
4. **Separate world-fit review from unsupported historical inference.** Review the exact capability implementation, source packet, estimand and falsifiers together. Synthetic task parameters need a justified analogue boundary, not a false claim that chat reveals all hidden state. Conversely, a reviewer should not demand historical evidence merely to attest an explicitly invented simulator feature. Preserve blocks, exact revisions and rival explanations; neither compilation nor citation membership should auto-approve a world.
5. **Connect theory comparison and prospective study design.** Give discovery/curation an explicit bounded literature-comparison path and record existing constructs/novel-to-library status. For a future live timing or topology study, first ensure subjects can use the relevant affordances and report negative/floor outcomes. Select independent swarm/block units and preregister contrasts before execution. Additional model calls are useful only after those functional and measurement issues are addressed.

These are implementation/deployment and evidence-quality gaps. More narrative, more spectral operators or repeated tests against unchanged contracts alone will not close them. A null or negative experiment can still complete a workflow; its status must reflect what it actually identifies.
