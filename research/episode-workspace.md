# Episode workspace

The workspace joins one original graph lead to its original comparator, saved rival explanations, source excerpts and recorded measurement layers. It is a read-only case view. Carrying a question into Environment authoring creates a local draft; construction, review, registration and execution remain distinct actions.

## Use it

1. Open an original graph lead in Observatory, or a matching graph behavior in Behavior library, then choose **Open episode workspace**.
2. Read the focal/comparator windows, saved feature direction, censoring and competing explanations. The comparison is the original data-selected comparison; this view does not choose a more favorable comparator.
3. Expand name sensitivity, strict temporal paths, actor/time records, literal wait/action candidates or static edge-count algebra. Each available layer has its own exact observation and recorded-proof references. Unavailable layers remain unknown.
4. Read bounded original excerpts and inspect their message IDs, content hashes and truncation information. A quoted excerpt is evidence to inspect, not a verified behavioral interpretation.
5. Edit a question that contrasts at least one rival and states a possible falsifier. **Compare supported study designs** carries the question and exact origin into a local guide covering six existing assignments, outcomes, cheap falsifiers and fit limits. Opening a form retains the draft while leaving live mode and every form value unchanged. Review any existing motivating behavior selection separately: origin context is not registered, attached to protocols or sent to subjects. A blank question blocks navigation and can be edited without losing the origin.
6. **Use question in Environment authoring** separately copies only question text. Select any motivating behavior explicitly there, choose required capabilities, then submit construction when the research backend and budget permit. A capability missing from the existing six study interfaces remains an explicit extension requirement.

The optional behavior is shown only when its exact version/hash matches the selected candidate and source references. Its saved model prose and critique remain hypotheses. Opening the case creates no model call, job, library version, experiment or status promotion. Draft text survives navigation within the current loaded app, but is not saved across reloads.

## API and bounds

`GET /api/episode-workspace` requires `selected_audit_id`, `selected_audit_version`, `temporal_audit_id`, `temporal_audit_version` and `lead_id`. An optional `behavior_id` requires `behavior_version`, and vice versa. Version fields are canonical positive integers. Duplicate, blank and unrecognized query parameters are rejected before packet construction.

Exact parent bodies, candidate fields, comparison windows, current measurement producer bytes and saved proof bindings are checked. The browser derives exact parents from the requested historical discovery version and verifies the returned source hashes before presenting quantities. A newer incompatible relevant audit blocks display rather than falling back to an older favorable one. The bounded inventory may lack old audit parents; that absence produces an unavailable view, not a reconstructed case.

The packet retains at most eight messages per side and 1,000 Unicode characters per excerpt, with original UTF8 content SHA-256, character count and truncation status. It checks all supplied evidence IDs against their original scopes, including IDs omitted from the visible excerpt. The packet is capped at 64 KiB. These are accepted presentation/body limits; they do not bound SQLite decoding allocations. Registered comparator choice, node universes, instrument variants, uncertainty and saved numeric values are preserved.

Base-source disagreement withholds the case. A missing, stale or failed channel gate withholds that channel's quantities. Known zeros remain zeros; missing observations remain unknown. A tiny nonzero graph energy may display as approximately zero with the stated display tolerance; its stored number is unchanged.

## What the checks mean

The case view checks local registry/body consistency, recorded proof bindings and current producer bytes. Its flags explicitly state `fresh_source_attestation=false` and `operator_rerun=false`. Opening it does not reread the remote export or local index, independently rerun a scientific operator, authenticate provider consumption, establish semantic accuracy or identify an effect.

Actor/time observations use their original author/time scope with no room predicate. Missing event rooms are not filled from the chat room. Literal markers and nearby WAIT records retain their controls, censoring and clock assumptions; proximity is not semantic accuracy. Static Hodge gradient/circulation discards time order and uses net named-reference counts; energy is not a message proportion. Curl and harmonic components remain unknown without declared faces. Strict temporal reference paths describe ordered references, not recipient exposure or causal influence.

For experiment selection, use the [experiment choice map](theory/experiment-choice-map.md). For the narrower existing correction-routing capability, see the [relay contract](theory/correction-relay-implementation.md). A graph lead or saved hypothesis does not establish that either world reconstructs the historical mechanism.

It also preserves a source error in the saved critique: a cited April 16 record reports a new Sheet with planned population/sharing, rather than a published Doc.
