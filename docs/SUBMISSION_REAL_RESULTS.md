# A broken reference became a usable document handoff

SocietyLab turned reported AI Village link failures into a narrower, executable question: **can a document owner and an independent checker recover access to one correct original, and does a private canonical-reference reminder help?**

The source is the saved September AI Village dataset: 2,000 real posts, version 1 of `dataset-1ac43f5141de`. Reports describe differing copied links, browser profiles, permissions and apparent access failures. They motivate the test; they do not reveal verified historical Google state. The preceding investigator and skeptic rejected a distinct novelty or historical mechanism claim.

## What the real agents did

Four fresh two-role teams ran through the actual Responses harness using `gpt-5.4-mini`. Each team had an owner, an auditor, one stable original document and 16 decision opportunities. Correct content, team permissions and initially authenticated profiles were held fixed. The auditor started with a deliberately nonresolving copied reference. Local executable tools modeled title search, exact navigation, profiles, clipboard and direct addressed messages. These are disclosed proxy semantics, not a reconstructed Google browser.

All teams received the same explicit goal and tool explanations. Two matched world pairs compared an 18-word neutral note with an 18-word canonical-check note. The two arms had identical tools, starting state and seeded schedules. An actual LLM builder and causal reviewer checked the new bounded world before subject execution.

| Preregistered measure | Neutral note | Canonical-check note |
|---|---:|---:|
| Independent fresh teams | 2 | 2 |
| Current original successfully opened by auditor | **2 / 2** | **2 / 2** |
| Actual model decision responses | 32 | 32 |

All four owners queued canonical references and all four auditors actually opened the current original. The oracle also checked correct content and authorization; owner access, queued text and a success report alone could not pass. Independent Drive search remained legal, so this does not establish that the owner message was necessary. An open receipt is not comprehension: only one team had a recorded auditor inspection of current content.

**What we learned:** this bounded reference-handoff task was solvable by real agents using the supplied tools. **What we did not learn:** the reminder improved success. Both arms succeeded, giving a paired difference of 0 percentage points; the registered 95% bounded interval spans −100 to +100 points, with sharp-null paired p = 1. Two pairs cannot establish benefit, equivalence, historical causation or a novel swarm mechanism.

The 64 distinct completed model responses include two invalid-output choices. Those consumed opportunities and remain in the replay; they were not silently retried. Fresh read-only checks matched every saved model input/output to the exact request and tool transition, replayed all outcomes, and checked source pins, archives and numerical facts.

## Earlier negative evidence remains separate

The earlier six-role, four-document pilot used 240 actual decisions and achieved 0/2 strict project completions in each arm. It remains saved. The new task changes scope and clarifies the common goal; comparing their success rates is not a randomized estimate of that redesign's effect.
