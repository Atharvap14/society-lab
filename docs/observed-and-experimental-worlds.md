# Logs, supplied environments and causal tests

Society Lab has two research entry modes. The current AI Village demonstration starts with **logs alone**. A researcher can also supply **logs plus an environment**: a task specification, files, tool contract or reviewed executable adapter. Supplying an environment does not automatically establish that it is the original world or that every tool is available.

The input mode determines what can be reused and what must be constructed. It does not change the distinction between observing history and generating a new experimental outcome.

| Input | Historical evidence available | Experimental preparation |
|---|---|---|
| Logs only | Retained source messages/events, explicit references and reported actions | Build a bounded analogue; declare invented task state, tool proxies and missing original information |
| Logs plus supplied environment | The same recorded evidence, plus the supplied environment's declared rules/files | Bind a reviewed adapter, reset and outcome oracle; check which original properties are preserved or approximated |

## The research loop

1. **Observe.** Import exact source versions. Cheap lexical or prompt-defined identifiers screen possible episodes. Retain unknown labels, missing opportunities and source scope. A saved message is a reported utterance; addressing is not proof of reading.
2. **Challenge.** LLM investigators and skeptics retrieve evidence and ordinary counterexamples. Register a candidate, a rival explanation or a rejection. Graph structure guides a question; it does not establish an influence mechanism.
3. **Construct.** Choose the smallest supported environment that makes the question testable. The builder declares the objective, subjects, action schema, communication rules, state transitions and outcome oracle. A separate reviewer can reject the proposed fit. Unsupported capabilities require an extension or a narrower disclosed analogue.
4. **Register.** Freeze assignment, interventions, starting-state generation, model/harness settings, schedule, stopping rules and analysis. Bind source and world versions. Original future actions and outcomes must not be inserted as if available at the branch point.
5. **Execute and check.** Fresh LLM subjects act through the harness. Tool results follow the registered world contract. Preserve incomplete runs and missing outcomes. Replay checks recorded transitions and numerical facts without rerunning subjects or proving historical causality.

## Tool proxies are an explicit fidelity choice

Unavailable tools may be represented by simulated tool semantics or a proxy. A deterministic tool transition does not imply a scripted subject agent. Real LLM agents can choose actions in a real executing state machine while the tool represents an abstraction of an original service.

The current single-document reference-recovery world holds correct content, viewer ACL and starting authenticated profiles fixed. One auditor reference starts broken. Two fresh LLM roles share the same explicit goal: the auditor must actually open the current original. Ten legal tools support title search, exact navigation, session switching, inspection, direct messages, reporting and waiting. Recreation and sharing are not part of this narrow task. The earlier broader task remains a separate diagnostic record; its primary was not changed or pooled. The new proxy does not reproduce original Google services, hidden histories or historical model policies. The assigned context-note comparison and generated setup are experimental inventions; matched two-role-team contrasts do not establish historical equivalence.

A fidelity card should declare task and artifact semantics; proxy/original tools; allowed recipients and delivery rules; memory and private information; schedules and costs; reset/isolation; oracle validity; subject model/harness; unsupported features. A successful schema compilation proves supported construction, not semantic fit or historical fidelity. Higher visual detail alone does not strengthen identification.

## Keep the library's evidence axes separate

Resolve every source through its exact ID, version and hash. Distinguish historical logs, producer-declared runtime telemetry, authored software fixtures, supplied imports and unknown/unavailable provenance. A live LLM experiment in a proxy world is controlled-world telemetry, not a new historical observation. A filename, model-written claim or current latest record cannot supply missing source provenance.

Preserve behavior status independently: candidate, rejected, hypothesis, infrastructure-tested, pilot-tested or replication-tested. Experimental evidence is additionally scoped by subject mode, registered world and intervention. An inconclusive pilot is not a confirmed mechanism; a completed replication is not automatic generalization. Exact reuse preserves identity; an editable copy preserves origin without copying outcomes as fresh evidence.
