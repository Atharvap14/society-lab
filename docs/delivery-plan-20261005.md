# Society Lab - one-hour delivery plan

Started 2026-10-04 21:19 UTC. Review target: 22:19 UTC (03:49 IST, October 5).

## Product outcome

People study agent societies by talking to a guide. Research can branch, revisit old evidence, and move between projects. Every source, behaviour, plan, world, run and result keeps its saved identity. Agents use the tools; people see what the guide did and inspect the evidence.

## Actions and acceptance checks

1. Finish the conversation experience: persistent project/chat context, cross-project `@` search, exact saved references, read/reuse/editable copy/branch. Switching chats while a real request runs must preserve both chats.
2. Show the guide's work: recorded working summaries, actual tool receipts, clear pending/completed/failed states, Markdown answers, safe embedded charts generated from exact experiment results. Private reasoning is not invented or exposed.
3. Make saved research discoverable: one saved-work home with clear Behaviours and Experiments collections. Show origin, version, evidence and review status. Support explain, compare, replay, reuse, copy, replicate and challenge as distinct intents.
4. Preserve replay meaning: local records, direct messages, shared-room posts, unknown audience and actions have separate lanes. Show only explicit addressed relationships. Replaying an old run must preserve a newer draft.
5. Run the frozen eight-step real-agent user scenario. Save predicted outcomes before acting; compare each step with UI, tool receipts and saved records. Report failures and corrections, not just passes.
6. Exercise generated long sequences and adverse transitions against actual backend and browser modules: stale writes, retries, copies of copies, forks, pending work, restoration and exact older versions. Preserve original results and prevent duplicate paid work.
7. Prepare submission materials: short project write-up PDF, optional real-results report, concise demo script, clean reproducible code handoff and repository readiness. The user reviews this version before final submission/publication.

## Saved-work intents

| User intent | Expected action | Integrity rule |
| --- | --- | --- |
| Understand a behaviour | Explain its definition, examples and limits | A candidate is not an established theory |
| Find evidence or counterexamples | Read exact sources and run discovery when requested | Discussion and name matches are not causal evidence |
| Read another chat | Read a pinned discussion revision | Keep the current chat and artifacts unchanged |
| Open/replay an old experiment | Load exact result and trajectory | Preserve the active draft; no new subjects |
| Compare old experiments | Show compatible outcomes and differences in design | Different worlds/units cannot be silently pooled |
| Reuse a plan or source | Link its exact saved identity | Reuse does not duplicate results |
| Change an old design | Create an editable draft with provenance | Copied outcomes and proofs are not new evidence |
| Replicate | Save a new plan and assignment, then explicitly run | Track fresh units separately |
| Branch an idea | Fork discussion and references | Future state/history remain independent |
| Resume later | Restore project/chat state and saved work | Exact versions remain accessible |
