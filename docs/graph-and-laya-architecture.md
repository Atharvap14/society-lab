# Graphs and prompt-defined behavioural measures

Society Lab uses Laya as the local, bounded identifier layer. A guide or investigator can propose a behaviour question and explicit positive, negative, unknown and non-example rules, then save the prompt and schema as an immutable rubric. A bounded measurement binds exact message and rubric versions. Classifier output proposes where to look; investigators retrieve evidence, check opportunity and counterexamples, and propose a separately reviewable experiment.

The eight starter rubrics cover contributions, qualified information, handoffs, commitments, reliance on evidence, corrections, returned help and shared-resource rules. They are proposed instruments, not validated scales. They use original concise adaptations of Gautam's private Kairosity Observatory rubric, with its Git blob recorded. The private source file is excluded from the release.

Laya's operational failures are retained as unknown. Missing runtime, insufficient memory, failed inference and abstention never become a negative observation or a substitute regex score. An atomic text label cannot supply a verified opportunity, recipient exposure, task outcome or causal mechanism. Episode assessment remains not assessable until its separate evidence requirements are met.

Three graph layers answer separate questions:

| Layer | Question | What a link means |
| --- | --- | --- |
| Communication and network analysis | Who addresses whom, and what structure appears? | A declared address or text mention under a specified instrument |
| Event evidence neighborhood | What recorded task, reply or tool reference surrounds this event? | A unique source-field match, with event hashes and diagnostics |
| Research artifact map | Which source, rubric, plan, world and result belong together? | An exact saved reference or explicit reuse relationship |

The event reader adapts a useful idea from Kairosity Observatory: keep source-grain references typed, traversable and attributable. It extends the existing events.v1 contract rather than importing its entire historical database. Missing, ambiguous and actor-conflicting references remain diagnostics. Content and private rationale are excluded from graph output. The API requires the exact run, version, hash, event ID and a bounded hop count.

Spectral/Laplacian and Hodge analysis remain exploratory math tools for declared graphs. Their operators, scope and source versions must travel with their results. A central node, circulation component or temporal path is not evidence that an agent read a message or caused an outcome. Causal claims require an identified intervention, unit of assignment, measurement and uncertainty.
