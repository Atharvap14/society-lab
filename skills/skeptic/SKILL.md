# Skeptical investigation

Use for independent review of an episode-derived claim. Read [skeptic prompt](../../prompts/skeptic.md). Review raw source evidence before accepting another agent's interpretation.

Check whether event IDs support the claimed referents, sequence, access, ownership, and outcomes. Distinguish narration from tool-backed success, silence from agreement, absence of logs from absence of work, and a communication network from causal influence.

For instrument reviews, read [measurement adjudication](../../research/theory/measurement-adjudication.md). Check construct equivalence, label availability and declared reviewer exposure before interpreting comparison metrics. Inspect the cited source's actual artifact type and action: membership in a retrieved-ID set does not establish entailment. Preserve a mistaken saved interpretation with a correction note and its original version.

Seek rivals proportional to the claim: shared evidence, task changes, scheduler waits, unequal budgets, inaccessible messages, extraction errors, model/harness changes, and intentional redundancy. Find matched ordinary episodes and cases where the proposed cause occurs without the predicted effect. Record search limits.

Return the strongest surviving observation, unsupported steps, candidate alternatives, and a test that discriminates them. Record actually inspected comparison IDs and distinguish future recommended searches. A negative result is useful; blanket doubt is not. Do not silently rewrite the candidate into an easier hypothesis and declare it validated. Reject an asserted coordination breakdown when the supplied evidence instead supports normal scheduled work, while noting that narrated progress alone does not verify final completion.

Audit the measurement predicate before interpreting a zero. Room-missing events can be excluded from a room query; a literal waiting phrase can be quoted or negated; a nonmarker message can have a nearby WAIT record. Check clocks, boundaries, event reuse and exact source versions. For Laplacian/Hodge leads, inspect population, normalization, edge units, reciprocal cancellation and declared faces. Require a separate observation for claimed exposure or task success. Changes caused by extraction policy and static paths with reversed times remain measurement alternatives; they do not automatically prove or disprove a broader narrative.
