# Causal methodology

Read [causal experiments](../../research/theory/causal-experiments.md) and [role prompt](../../prompts/causal-methodologist.md) for experimental design or effect interpretation.

Define the intervention as an observable supported operation. Thought planting can be private context insertion; do not claim access to a latent belief or unavailable reasoning stream. Record content, channel, timing, recipients, and actual delivery. Use neutral and no-insertion controls when required to isolate content from added context.

For event-triggered notes, read [intervention timing](../../research/theory/intervention-timing.md). Eligibility uses only scoped observations and completed events before the next decision. Keep the same arm-blind rule in both content arms, permit one insertion with no fallback, and retain nondelivery in the whole-swarm policy estimand. Delivered-only comparisons do not become causal estimates. An observed-state controller, proposed-action interception, rollback, and repeated sequential randomization require different registered contracts; never substitute one for another.

Fix estimand, randomization unit, outcomes, horizon, exclusions, reset rules, and analysis before confirmation. Randomize independent whole swarms for group effects. For network effects, define exposure and assignment probabilities; agents and messages inside a run are not independent trials.

Reject future-outcome leakage, unmatched tool access or budgets, undocumented post-treatment conditioning, unverified reset, and adaptive protocol changes presented as preregistered. Use a pilot to repair instrumentation, version changes, then run fresh confirmation.

Compute effects with design-aware code and report uncertainty. A scripted deterministic end-to-end run validates infrastructure, not LLM behavior. Preserve failed and aborted runs by arm. State controlled, measured, assumed, and unresolved factors; an agent cannot guarantee freedom from every confound.

For world-fit review, distinguish a historical claim from an implemented synthetic capability. Check the host capability catalog, scoped-packet probes, and pinned implementation sections through `read_environment_source`; do not demand historical transcripts to prove that an invented simulator implements multicast or an oracle. A supported capability does not demonstrate that a contrast isolates the proposed mechanism. Name an absent executable feature separately from absent evidence or an unidentified mechanism. Cite only theory reference names actually listed in the packet. Return a blocked or revision-needed judgment when operational controls are missing, while retaining the exact blueprint hash and earlier judgments.

For the documented [relay factorial](../../research/theory/correction-relay-implementation.md), preserve scheduled boundaries even if B waits or returns invalid output; a realized-relay trigger conditions on treatment response. Pair the stated exogenous projection, not complete inventories. The interaction compares timing-policy effects under assigned bypass, not relay mediation or reminder efficacy. Retain the whole grid; incomplete execution has no aggregate estimate. Default intervals and interaction p-values are unavailable.
